# Public Release Scope (v15)

Tingfeng Controller v15 uses runtime in-memory nickname glyph capture by default and contains no hardcoded nickname templates, personal screenshots, or startup calibration fixtures. Runtime logs, local configs, and captured screenshots are excluded from the repository.

Run `npm test` in the repository root to verify distribution integrity, import completeness, manifest checksums, and core logic without launching the game client. Prebuilt Windows x64 binaries for Tingfeng v111 and Tingyuan v21 are distributed via GitHub Releases and verified against `release-manifest.json` during setup.
