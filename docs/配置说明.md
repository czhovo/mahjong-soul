# 安装与配置

## 环境

Windows 10 1903+、Node.js 22+、Windows x64 Python 3.12、Steam 版雀魂。`node`、`python` 需要能在 PowerShell 中运行。

```powershell
powershell -ExecutionPolicy Bypass -File .\setup.ps1
```

安装脚本建立 `.venv`、安装锁定的 Python 依赖、从官方源下载并校验 AutoHotkey 2.0.30，再从本仓库 GitHub Release 下载并校验 Windows x64 决策引擎压缩包（听风 v103 与听元 v13 各三档），部署到 `engines/` 与 `sanma/engines/`，并复制校验 WGC DLL 与窗口输入组件。安装和正式启动均不执行样本识别、搜索预热或标题栏点击自测。

```powershell
.\setup.ps1 -Python 'C:\Python312\python.exe'
.\setup.ps1 -SkipPython -EngineZip '.\mahjong-soul-engines-v103-v13-windows-x64.zip'
```

`-SkipPython` 要求已有 `.venv`。`-EngineZip` 可指定手动从 GitHub Release 下载的引擎压缩包，跳过在线下载但仍执行完整 SHA-256 校验。

## 隐私与结果处理

公开版仅保留 `--name` 自动内存昵称匹配路径：自动从大厅左上角或牌桌本方头像下方采集昵称字形，仅在内存中用于匹配本方和牌页及终局排名行。无需指定昵称或显式添加 `--name`（传入 `--name` 行为相同），不包含任何预置个人昵称模板。程序不识别头像，不保存本方和牌页与整场终局页，不输出个人和牌、整场排名、PT 变化等结算信息。终局页面及确认／再来一场按钮仍照常识别和点击；对局决策所需的场次、风位、点数和每局点数结算仍按原逻辑处理。

## 游戏画面与牌面

公开版 v12 使用编码牌面、默认桌布与橙色牌背。建议游戏内容区 1920×1080；也支持等比例窗口尺寸。WGC 通过 HWND 读取窗口纹理，保持原始像素；1920×1080 内容区对应 1922×1112 输入，客户区起点 `(1,31)`。不同边框样式只做裁边或补边，不缩放游戏内容。

关闭雀魂后，从自己的游戏资源生成编码牌面：

```powershell
.\.venv\Scripts\python.exe patch-tiles.py --game-dir '<SteamLibrary>\steamapps\common\MahjongSoul' --install
```

游戏中选择默认牌面。备份和生成文件保留在 `private`，不随仓库分发。游戏更新改名时可用 `--bundle 文件名.majset` 指定；资源不匹配会停止。

之后切换标准／编码牌面：

```powershell
powershell -ExecutionPolicy Bypass -File .\switch-tiles.ps1
```

游戏正在运行时，同一行倒计时 10 秒，回车跳过剩余等待；关闭游戏、校验并切换后重新打开。游戏未运行则只切换。安装对应的路径与校验值在 `private/active-tiles.json`。

## 参数

| 参数 | 作用 |
| --- | --- |
| `-3` / `-4` | 三人／四人场，互斥，默认四人。三人场没有对家、不能吃。 |
| `-b` / `-s` / `-g` / `-t` | 铜／银／金／玉之间，互斥。 |
| `-f` | 跳过开局点击，等待进入对局；终局流程正常。没有场次参数时必须带此参数。 |
| `-l` | 全程使用降档搜索预算。 |
| `-d` | 显式启用全部采集画面归档，默认关闭。 |
| `--lag` | 开启卡顿恢复，默认关闭。 |
| `--naku` | 开启鸣牌等待信息推断，默认关闭。 |
| JSON 文件路径 | 可选配置文件，最多一个，参数顺序可交换。 |

默认四人场听风 v103、三人场听元 v13。默认 5.5 秒；识别到长考剩余 ≤5 秒后，当前搜索正常结束，后续决策切换为 3.5 秒并在终端提示；新一局恢复。

## JSON 与目录

复制 `config.example.json` 为 `config.local.json`：

```powershell
node resident.mjs config.local.json -t
```

| 字段 | 默认值及含义 |
| --- | --- |
| `autoRematch` | `true`，终局后继续；`false` 在整场结束时退出。 |
| `initialScores` | 可选，按风位顺序；四人默认各 25000，三人各 35000，优先使用可核实的画面点数。 |
| `scheduledWinds` | 三人场使用，`1` 东风、`2` 半庄，默认 `1`。 |
| `pollMs` | 外层等待循环间隔，默认 `250` ms，并非识别超时。 |
| `directory` | 可选日志目录，默认四人 `test-evidence/resident`、三人 `sanma/test-evidence/resident`。 |

Python 优先取 `TINGFENG_PYTHON`，其次 `.venv/Scripts/python.exe`，最后 PATH 中的 `python`。本地配置、运行日志和保存的截图可能含有隐私，只应保留在本地。不要同时运行多个执牌进程操作同一窗口。

维护者可手动执行 `npm test` 检查发布完整性；它不属于启动流程，不读取个人截图或执行游戏点击。
