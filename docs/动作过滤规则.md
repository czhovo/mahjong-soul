# 局内动作过滤与执行规则

听风执牌 `v12` · 四麻听风 `v103` · 三麻听元 `v13` · `recognize v7` · `execute v3`

> 本文档为 `mahjong-soul` 工作区内动作过滤规则的唯一权威参考，供主控接口与四麻/三麻决策引擎共同遵循。

---

## 1. 基础动作过滤

| 动作 | 允许条件与限制 |
|---|---|
| 自摸、荣和 | 有和牌机会时必须和牌，禁止见逃。和牌动作（`TSUMO` / `RONG` / `HU`）绝不送入决策引擎，由局内自动和牌与四阶段 `AutoWinGuard` 保护承接。偶然役（岭上开花、海底摸月、河底捞鱼、抢杠等）绝不计入静态有役判断。 |
| 弃牌 | 只能打手中实际持有的牌。立直后只可摸切。三麻摸牌回合普通弃牌与立直宣言牌始终排除北风（仅在无 `KITA` 且剔除北风后没有任何其他合法动作的极端边界保留 `PLAY Z4` 兜底）。 |
| 吃 | 仅四麻，可吃上家的数牌，手中须有组成顺子的另两张。吃后禁止打同种牌或筋食替牌。首次破门清须满足第 3 节条件。 |
| 碰 | 须持有至少两张同种牌，碰后有合法弃牌，且不能立即打出所碰的同种牌。首次破门清须满足第 3 节条件。 |
| 吃碰共通 | 本方已立直、牌山已空或来牌是本方自己的弃牌时，排除吃碰。 |
| 大明杠 | 三麻、四麻均禁止。 |
| 暗杠、加杠 | 须有对应杠选项。暗杠须四张同种；加杠须已有对应的碰且手中有第四张。未立直时，须同时满足余牌至少 5 张、全场已有杠少于 3 个、无人立直、普通弃牌参考向听数为 0～2、杠后向听数不增加。向听数无法确定时排除。 |
| 立直后杠牌 | 只允许游戏提供的暗杠，须由本次摸牌凑齐四张。四麻还校验杠后仍听牌且听牌种类不变。 |
| 拔北 | 仅三麻。手中须有北、余牌至少 1 张、全场杠数与拔北数之和小于 8。立直后只允许拔刚摸到的北。除国士无双路线外，首次决定拔北后开启自动拔北，后续自动拔北的中间帧不送决策，用更新后的拔北数和最终补摸牌决策；默听听牌状态摸到北风时不走引擎，若出现自摸按钮则点自摸，否则点拔北。 |
| 九种九牌 | 始终排除流局。只有「流局 / 跳过」时选跳过；还有其他合法动作时保留其他动作。 |
| 跳过 | 仅对手来牌反应窗口下与合法吃碰一起参与比较。自摸/弃牌回合放弃立直、杠或拔北后以具体弃牌作为候选；**弃牌窗口即使出现加杠、暗杠、立直、拔北、跳过等自家动作按钮，只要决策选择弃牌（`PLAY`），必须直接点击目标手牌弃牌，不得点击跳过按钮**。 |

## 2. 立直

- **基本资格**：门清、未立直、至少 1000 点、打出宣言牌后听牌。余牌四麻至少 4 张，三麻至少 3 张。
- **末局及延长局**：支付 1000 点后名次下降，禁止立直；同点按顺位优先级计算；末局点数无法核实时也排除立直。
- **末局第一名**：支付后四麻至少 30000 点、三麻至少 40000 点，并且该宣言牌对应的和牌率至少为 60%，才允许立直（和牌率缺失时排除）。其他名次只检查支付后是否掉名次。
- **默听无役豁免**：**末局及延长局的立直限制（掉名次禁立直、末局一名点数与 60% 和牌率门槛）均不得阻止默听无役时的立直动作**；逐张判定宣言牌，若打出该牌后默听静态无役（不计偶然役），该宣言牌豁免上述末局立直限制。
- **默听役满**：逐张检查宣言牌。若所有仍可实现的合法默听和法均已达到役满或累计役满，且立直既不能增加和法也不能提高点数，则排除该宣言牌。国士无双路线禁止立直。

## 3. 首次破门清

由决策引擎逐个检查「吃碰组合＋鸣后弃牌」，满足任一条即进入评分；已经破门清后免除此项筛选（暗杠与三麻拔北不破门清）。无论三麻、四麻，门清状态下首次鸣牌必须满足以下条件之一：

1. **碰役牌**（`value_honor_pon` → `碰役牌`）：包括白、发、中、场风、自风。
2. **吃碰赤五或宝牌**（`red_offer_pon` / `red_offer_chi` / `dora_pon` / `dora_chi`）：吃碰对手打出的赤五，或吃碰宝牌。
3. **进听**（`tenpai` → `进听`）：吃碰并弃牌后进入听牌。
4. **三色支持**（`three_suit_pon` / `three_suit_chi`）：碰数牌时，另两门各有同数字的至少两张（对应暗杠也算）；吃牌时，另两门各自持有目标顺子三个数字中的至少两种。
5. **保有同一项可副露役结构**：鸣前与鸣后弃牌后保有同一项可副露役结构，包括役牌刻、断幺九、一色手、混老头、一气通贯、三色同顺、三色同刻、三暗刻、对对和（须有四组刻杠）、三杠子、绿一色、字一色、清老头、四喜或三元牌结构。
6. **双未见役牌对子**（`two_live_value_pairs` → `役牌机会`）：鸣后弃牌仍保留两种不同的役牌对子，且每种都至少有一张未见。

- **终端展示**：引擎按规则 1→6 顺序输出全部命中原因至 `first_open_reasons`；接口侧终端日志仅取按规则 1→6 排序后最高优先级的**一项**中文理由插入 `决策 <动作>` 与指标之间。

## 4. 国士无双路线

- **启用**：开局恰好九种幺九时暂时启用。到本方已有三次弃牌后的摸牌回合，仍未达到十种则解除；摸出已有幺九的对子不重置期限。任何时刻达到十种即锁定，不受三巡期限限制。
- **弃牌**：中张可弃。每种幺九至少留一张。若已有幺九对子，普通弃牌后须至少保留一对；有两对可拆一对，有三张可打一张。
- **和牌与鸣牌**：只允许国士自摸或荣和。禁止立直、吃、碰及所有杠。
- **三麻拔北**：关闭自动拔北。持有至少两张北才允许单次拔北，至少留一张。
- **提前解除**：所缺某种幺九四张均已在手外可见；或本方没有对子且每种幺九在手外均已见至少三张；或可靠余牌数已不足以完成国士。
